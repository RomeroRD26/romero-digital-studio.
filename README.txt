CONTACTO
- El botón de WhatsApp funciona cuando configures whatsappNumber.

PUBLICACIÓN GRATUITA
Puedes publicar estos archivos en un servicio de alojamiento estático como GitHub Pages o Netlify. Crea una cuenta siguiendo la edad mínima y condiciones del servicio; si hace falta, pide ayuda a tu padre, madre o tutor.
